# Job Portal

A full-stack Job Portal web application that connects job seekers with recruiters. Users can search and apply for jobs, while recruiters can post and manage job listings.

## Features
- User & Recruiter Authentication
- Job Search and Application
- Company Management
- Job Posting & Management
- Applicant Tracking

## Tech Stack
**Frontend:** React, Vite, Redux Toolkit, Axios, Tailwind CSS

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT

## Installation

```bash
git clone https://github.com/Anshul1632/job-portal.git
cd job-portal
```

Install dependencies:

```bash
cd backend && npm install
cd ../frontend && npm install
```

Run the project:

```bash
# Backend
cd backend
npm run dev

# Frontend
cd frontend
npm run dev
```
